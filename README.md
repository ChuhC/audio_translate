# 音频转文字

安装 FFmpeg 并将其加入 PATH，然后运行：

```powershell
uv run main.py .\video.mp4
uv run main.py --help
```

输入 MP4 时，脚本会生成或复用同名 `.mp3`，再将转写内容保存为同名 `.txt`。如果 MP4 已不存在，但同目录有同名 MP3，会直接使用 MP3，无需转换或安装 FFmpeg。也可以直接输入音频文件。

转写时终端显示进度条、百分比和已处理时长；续跑会从检查点对应的进度开始显示。

转写时会在音频旁保存同名 `.checkpoint.json`。暂停或中断后用相同命令重新运行，会从最近完成的语音片段继续。检查点会在转写完成后保留，重复运行会提示已完成。更换音频后检查点不再适用；如需从头转写，请自行移走或删除旧的 `.txt` 和 `.checkpoint.json`。已有 `.txt` 却没有检查点时，旧文本会自动备份为 `.txt.bak`（如已存在则追加编号），然后从头转写。
